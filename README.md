### 👨‍💻 Sobre mí

Soy estudiante del programa **Análisis y Desarrollo de Software (ADSO)** en el SENA. Me apasiona el desarrollo de soluciones digitales y la construcción de software con buenas prácticas, arquitecturas limpias y metodologías ágiles.

- 🎯 **Enfoque actual:** Profundizando en desarrollo web full stack, diseño de bases de datos y arquitectura de software.
- 🎨 **Lado creativo:** Músico (guitarra, tiple, requinto y ukelele), apasionado por el dibujo, la creación visual y la edición de video.
- 🏐 **Deporte:** Practicante aficionado de voleibol.
- 🌱 **Origen:** Orgullosamente de Guadualito (Palermo, Huila), valorando siempre la disciplina, el aprendizaje continuo y la adaptabilidad.
